# Pact

**Money agreements your agent keeps.** Tell Pact what you and your people want: "when the PS6 drops below $450, buy it for Sam — split three ways, max $160 each". Everyone pre-commits their share with PayPal, and an agent watches, pays and settles, even while you're offline.

Built for the [PayPal AI Hackathon](https://paypalaihackathon.devpost.com/) with PayPal (Orders v2, Vault v3, Payouts, Invoicing, Webhooks, JS SDK v6), Claude, and Cloudflare.

> Work in progress. See [docs/spec.md](docs/spec.md).
